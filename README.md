# homebrew-tap

Homebrew formulas for [macadmins/contour](https://github.com/macadmins/contour).

```bash
brew install tux234/tap/contour       # CLI
brew install tux234/tap/contour-mcp   # read-only MCP server
```

Formulas install the signed release binaries (macOS arm64, Linux arm64/x86_64). A scheduled workflow bumps them when a new contour release is published.
